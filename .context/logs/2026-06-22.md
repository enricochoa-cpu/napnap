## Decisions

1. **Wake Up is gated, not redesigned** — the dead-end is removed by hiding the tile when there's nothing to wake from; the focused WakeUpSheet remains the path for active/unended sleep. KF-10 became defensive as a result.
2. **KF-04 is conservatively gated** — "NAP NOW" only fires when genuinely overtired *and* a nap still fits before bedtime, to never override the legitimate "head to bedtime" case (this is the recurring §1 bug class, so the guard is deliberate).
3. **KF-06 touches a documented decision** — the FAB was intentionally live-only; un-gating it for recent completed nights improves the morning-after flow while keeping editing in the entry editor. Comment updated to reflect new intent.
